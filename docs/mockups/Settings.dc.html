Saison

Hiver : seuls les appareils de chauffage sont pilotés. Été : seulement la climatisation. Coupé : rien n'est envoyé. Un appareil réversible suit la saison.

Présence globale

Personnes découvertes dans Home Assistant. La maison est vide quand toutes les personnes suivies sont absentes.

Mode vacances

Tout passe en Absent ou Coupé, puis relance avant le retour, préchauffage compris.

Relance prévue le 8 novembre vers 16:20 pour être à la consigne à 18:00

Modifications manuelles

Une consigne changée dans Home Assistant ou sur l'appareil est respectée comme un boost, puis le planning reprend.
